Observation boundary

Each connection keeps its capture source and recording scope. TCP observations with a matching initial SYN fingerprint and start time are correlated. Counts use one canonical observation; overlapping links are never summed.

Missing SYNs remain separate observations. Capture loss is reported as unavailable unless measured. Connections crossing a capture rotation can be incomplete.

Monitoring records use schema hiot.monitoring.v1. Medical evidence contains selected protocol metadata; raw PCAPs contain the original lab traffic. Configured device roles are separate from observed protocol facts. Snapshot analysis introduces processing delay.
